# 🏅 Projeto Atleta

Aplicação desenvolvida em **JavaScript** para cadastrar atletas e calcular
informações como **categoria**, **IMC** e **média válida** das notas.

---

## 📌 Funcionalidades

- Cadastro de atleta
- Cálculo da categoria por idade
- Cálculo do IMC
- Cálculo da média válida (descarta maior e menor nota)
- Exibição dos dados no console

---

## 🚀 Tecnologias utilizadas

- JavaScript
- Git e GitHub
